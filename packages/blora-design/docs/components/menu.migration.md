# Menu

New in 2.0 as a native link list. Sidebar destinations still use `<blora-sidebar-nav>`. Overlay actions still use `<blora-dropdown>`.

```html
<nav class="blora-menu" aria-label="文档">
  <p class="blora-menu__title">指南</p>
  <a class="blora-menu__item" href="#" aria-current="page">开始</a>
</nav>
```
