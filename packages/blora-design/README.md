# @bloret-crew/blora-design

Blora Design 2.0 — a token-driven, accessible, zero-dependency Web UI design system.

**Status: 2.0.0-alpha (under active refactoring)**

See the [refactor spec](../../Blora-Design-2.0-Refactor-Spec.md) for the full implementation specification.

## Installation

```sh
pnpm add @bloret-crew/blora-design
```

## Usage

```js
import "@bloret-crew/blora-design/tokens.css";
import "@bloret-crew/blora-design/foundations.css";
```
